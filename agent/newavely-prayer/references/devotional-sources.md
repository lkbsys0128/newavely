# 날짜별 생명의삶 확인

요청 날짜의 제목과 성경 범위를 확인할 때만 사용한다. 이 문서의 주소는 검색 시작점이며
특정 날짜의 내용이 이미 검증되었다는 뜻이 아니다.

## 공식 출처

- 두란노 생명의삶 날짜별 말씀:
  `https://www.duranno.com/qt/view/bible.asp?qtDate=YYYY-MM-DD`
  `YYYY-MM-DD`를 서버가 확정한 기도회 날짜로 바꾼다.
- CGN 퐁당 생명의삶 목록:
  <https://www.fondant.kr/series/00090200-0000-0000-0000-00000000071b?category=episode>
  목록이나 해당 회차에서 요청 날짜·제목·본문 범위가 함께 일치하는지 확인한다.

## 확인과 제출

1. 공식 페이지의 날짜, 제목, 성경 범위를 함께 확인한다. 사이트의 오늘 표시나 검색 스니펫만
   사용하지 않는다. 두란노 접근이 막혀도 확인 없이 성공으로 표시하지 않는다.
2. 정확한 회차를 확인할 수 있는 공식 URL을 `devotional.sourceUrl`에 넣는다.
   목록으로 확인했다면 목록에서 해당 날짜의 메타데이터가 실제로 표시되었어야 한다.
3. `date`는 요청 날짜와 같게, `title`은 공식 제목, `passage`는 책·장·절 범위로 적는다.
   `book`과 `chapter`는 함께 제공한 `bible-books.json`의 번호·장 범위를 사용한다.
   `verifiedAt`에는 실제 확인 시각의 UTC ISO 8601 값을 넣는다.
4. `sourceUrl`은 비공개 작업 검증용 메타데이터다. 기도회 링크, `notes`, 상태 메시지,
   최종 사용자 답변에 생명의삶 URL을 넣지 않는다.
5. 서버는 성경 책·장 링크를 별도로 생성한다. 장 링크가 특정 절만 보여 준다고 설명하지 않는다.
6. 해설, 가사, 성경 본문 전체를 수집하거나 기도회에 복사하지 않는다.

미공개 미래 날짜, 날짜가 다른 자료, 확인되지 않은 제목은 제출하지 않는다.
필요한 정보만 `needs_input`으로 보고하고 다른 날짜의 자료로 대체하지 않는다.
